1.8
```
Los tres son canales de comunicación que los OS o lenguajes de programación ofrecen para que un programa los pueda usar.
stind (standard input): canal para recibir datos ya sea desde el teclado, un archivo o otro dispositivo
stout (standard output): canal para que el programa envie los datos ya sea hacia el monitor, un archivo o otro dispositivo
sterr (standard error): canal para que el programa envié los errores o advertencias permitiéndole que solo pasen por el canal stout los datos correctos.
```
